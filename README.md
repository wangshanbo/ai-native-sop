## 我相信

> "Prompt engineering 已死"是不会 ship 的人卖的鸡汤。
> AI 真正的杠杆来自**上下文工程** —— 每一轮对话都要把你的代码规约、业务不变量、review SOP 喂给模型。

> 瓶颈不再是用哪个模型，是**你能把多少生产级上下文持续放在模型面前**。
