## 一条主线

哪怕大模型越来越强，最强最贵的模型也永远不会便宜到人人都用得起。所以这个系列写出来，是为那些不能拿一个工资烧 token 的开发者。70 分的模型加上一套强 SOP，能写出 80 分的代码——比 80 分的模型加弱 prompt 写出 85 分但贵 10 倍的代码，更适合普通团队跑长期。
